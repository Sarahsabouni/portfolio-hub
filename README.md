## Portfolio standards

Every completed project will include:

- A redacted/importable n8n workflow export
- Architecture and data-flow documentation
- Synthetic test fixtures and expected outputs
- Failure-path and recovery documentation
- Security and privacy notes
- A short demo and operator runbook

## Important note

All examples use synthetic or redacted data. These projects are work samples and learning demonstrations, not claims of client production deployments or compliance certification.
